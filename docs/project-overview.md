# Waei Consult — Project Overview

## Overview

Waei Consult is a professional Arabic corporate consulting website.

The website introduces the company, its consulting services, methodology, values, and target clients.

## Primary Goals

1. Establish trust
2. Explain services clearly
3. Communicate Waei's professional positioning
4. Help potential clients understand how Waei can support them
5. Encourage contact

## Audience

- Business owners
- Managers
- Board members
- Executive managers
- Startups
- SMEs
- Family businesses
- Medium and large organizations

## Website Characteristics

- Arabic-first
- RTL
- Responsive
- SEO-focused
- Static
- No backend
- No authentication
- No database
- No dashboard

## Technology

Angular 21
TypeScript
Standalone Components
Tailwind CSS if configured
SSR / prerendering where appropriate
