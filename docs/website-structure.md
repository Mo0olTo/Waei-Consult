## Routes

/

 /about

 /services

 /services/:slug

 /why-waei

 /clients

 /contact

## Home Page

The homepage should tell a clear story.

Recommended order:

1. Header
2. Hero
3. Waei introduction
4. Core services
5. Why Waei
6. Values
7. Target clients
8. Strong CTA
9. Footer

## About Page

Suggested sections:

1. Page hero
2. Who we are
3. Vision
4. Mission
5. Goal
6. Values
7. CTA

## Services Page

Show all six service categories.

Each service should contain:

- title
- short description
- list of capabilities
- CTA

## Service Details

Optional route:

/services/:slug

Each service detail page should contain:

- title
- introduction
- service capabilities
- relevant CTA

Do not create service-specific claims that are not in the official content.

## Why Waei

Sections:

1. Data-driven methodology
2. Strategic partnership
3. Local experience / international standards
4. Proactive approach

## Clients

Show the four target client categories.

## Contact

The contact page should only include real contact information once provided.

Do not invent phone numbers, emails, addresses, maps, or social media links.

## Footer

Include:

- brand
- short description
- navigation
- services
- contact information when available
- copyright
