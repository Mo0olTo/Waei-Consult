# Waei Design System

## Design Goal

Create a premium consulting experience that communicates:

- Trust
- Professionalism
- Precision
- Strategy
- Stability

## Visual Direction

Use a clean corporate visual system.

Avoid excessive:
- gradients
- shadows
- animations
- decorative elements
- glassmorphism
- generic SaaS visuals

## Colors

The final brand colors should be taken from the approved Waei brand identity/logo.

Do not invent official brand colors if the brand assets have not been provided.

Until brand colors are provided, use a neutral temporary palette that can be replaced through design tokens.

## Typography

Arabic typography is a first-class requirement.

Use one primary Arabic font family consistently.

Recommended characteristics:

- excellent Arabic readability
- multiple weights
- professional appearance
- good screen rendering

## Spacing

Use a consistent spacing scale.

Do not use arbitrary spacing values throughout the project.

## Container

Use a consistent max-width container.

All major sections should align to the same visual grid.

## Buttons

Primary button:
- clear
- high contrast
- strong CTA

Secondary button:
- visually quieter
- still accessible

## Border Radius

Use a consistent radius system.

Avoid mixing many unrelated radius values.

## Cards

Use subtle borders/shadows.

Cards should support content hierarchy rather than become decoration.

## Icons

Use one icon family consistently.

Do not mix random icon libraries.

Icons should support the meaning of the content.

## Responsive

Mobile:
- stacked sections
- readable typography
- large touch targets

Tablet:
- balanced grids

Desktop:
- strong whitespace
- multi-column layouts where useful

## Accessibility

All colors and interactions must remain accessible.
